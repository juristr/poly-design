# PolyDemo Design

Shared React component library for the PolyShopping demo.

## Requirements

- Node.js 20+
- pnpm 10+

## Install

```sh
pnpm install
```

## Validate

```sh
pnpm exec nx run-many --target=lint,test,build --all
```

## Package

The package is published as `@polydemo/tusky-design`.

```sh
pnpm exec nx build @polydemo/tusky-design
```
